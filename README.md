# BLINKITA.SI V1

Prva dejanska responsive front-end verzija glavnega BLINKITA portala.

Vključeno: BODY, MIND, TIME, LIFE, CIRCLE, SHOP, BLINKITA LIVE, BLINKITA AI, BLINKITA WORLDS, plavajoči Tzolk'in widget, modal za izračun, osnovna košarica in scroll animacije.

V1 uporablja placeholderje za fotografije, video, Facebook Live, komentarje in Tzolk'in podatke. Obstoječi tradicionalni Tzolk'in engine se priklopi v naslednji fazi.

Odpri `index.html` v brskalniku.
